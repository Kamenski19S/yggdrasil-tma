# Имир — проявление из белого столба памяти

Персонаж — **Имир**, проявление утраченной памяти. Пользователь уточнил имя: прежнее «Мимир» было оговоркой. Имена подготовленных файлов и костей оставлены для совместимости. Внутренние имена существующего памятника `muspelheimYmirPillar` сохранены, чтобы не менять геометрию и связанные координаты. Это добавление персонажа и его появления; новые задания, награды и диалоги не добавлены.

Модель: **Storm Golem - Lightning Elemental**, автор **Pigcraft**, **CC BY 4.0**.
Источник: https://sketchfab.com/3d-models/storm-golem-lightning-elemental-3779f41add4a4a71a1cae6bf9ef27b58
Лицензия: https://creativecommons.org/licenses/by/4.0/
Авторство и изменения доступны на карте Муспельхейма, исходные метаданные автора сохранены в GLB.

## Подготовка

Исходный GLB: 112 423 928 байт, 1 986 670 треугольников, 21 часть, без скелета и анимаций. Подготовленный GLB: 8 933 456 байт, 131 428 треугольников, один skinned mesh, 23 кости. При упрощении ограничена относительная геометрическая ошибка 0,006; исходные UV и нормали учтены. Нормали, UV и веса упакованы, позиции оставлены Float32. Используется поддерживаемое Three.js расширение KHR_mesh_quantization.

Все **три исходных изображения 1024 × 1024 сохранены побайтно**, без перекрашивания и изменения разрешения: цвет, metallic/roughness, нормали. Материал, его каналы и двойная сторона сохранены. Проверена фактура на отдельном рендере до и после добавления костей.

Риг: таз, позвоночник, грудь, шея, голова; плечи, руки, предплечья, кисти и ладони; бёдра, голени, стопы и носки. Четыре влияния на вершину. Ключевые анимации `idle`, `greet`, `walk_loop` созданы для этой модели; чужая анимация не заимствована. Движения приветствия умеренные, стопы выровнены по реально деформированным вершинам.

Файл модели имеет рост примерно **1 метр**. В сцене Vicki ростом 1,8 м занимает 13,94 единицы; Имир занимает 13,94 / 1,8 ≈ 7,744 единицы. Пропорции не растянуты.

Подготовка (meshoptimizer нужен только для повторной обработки исходника):

```sh
npm install --no-save --no-package-lock meshoptimizer
mkdir -p output
node scripts/prepare-muspelheim-mimir.mjs /path/to/storm_golem_-_lightning_elemental.glb output/mimir-static.glb 65000
node scripts/rig-muspelheim-mimir.mjs output/mimir-static.glb public/img/models/Muspelheim_Mimir.glb
```

В репозитории сохранён gzip/base64 в `assets/ice-source/Muspelheim_Mimir.glb.gz.b64.parts`. Обычный prebuild восстанавливает GLB в public; исходные 108 МБ не добавлены в репозиторий.

## Появление в мире

Имир мирный. При приближении Vicki ближе 40 единиц к столбу на той же высоте он за 2,4 секунды выходит из его передней грани; приветствует, затем спокойно двигается и поворачивается к героине. Старт и конечная точка рассчитаны от реального bounding box столба. При удалении дальше 65 единиц возвращается в столб и исчезает. Анимация и появление останавливаются при паузе, скрытии приложения, падении или гибели Vicki.

Столкновение включается после появления; пока Вики стоит в конечной точке, появление не завершается, чтобы персонаж не материализовался внутри неё. В списки противников Имир не включён. Оружие, цвет столба, структура существующей локации и прежние боевые настройки не менялись.

## Проверки

`node scripts/test-muspelheim-mimir.mjs` проверяет 23 кости, три клипа, рост, сохранение поверхности в нейтральной позе, движение головы, нормированные веса, карты исходного материала, появление/паузу/возвращение, конечную точку вне столба и безопасное столкновение. Можно передать исходный GLB первым аргументом для побайтной проверки всех изображений. Дополнительно прошла `npm run build`.
